|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| :-: | :- | :- | :- |
|UC1|Сотрудник кол-центра, система кол-центра, сервис расчета ставок|Получение ставок по API|1.Сотрудник заходит в систему кол-центра и нажимает кнопку получения ставок. 2. Система кол-центра отправляет запрос в сервис расчета ставок. 3. Сервис расчета ставок возвращает ставки по API. 4. Сотрудник видит ставки на интерфейсе.|
|UC2|Сотрудник бэк-офиса, АБС, сервис расчета ставок|Заполнение ставок в АБС|1. Сотрудник заходит на страницу расчета ставок. 2. Сотрудник выполняет расчеты. 3. Расчеты отправляются по брокеру сообщении в сервис расчета ставок.|
|UC3|Сервис Debt_to_SFTP, SFTP-сервер, сервис расчета ставок|Отправка файла ставок на SFTP-сервер|1.Сервис Debt_to_SFTP раз в день забирает данные по АПИ из сервиса ставок. 2. Файл отправляется на сервер|
|UC4|Сотрудник партнерского кол-центра, Партнерская система кол-центра|Получение файла ставок|1. Сотрудник нажимает в своей системе кнопку выгрузки файла. 2. Файл выгружается сотруднику.|
